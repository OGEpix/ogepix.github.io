Privacy Policy

Applies to: Hermes Workspace · Last updated: 8 October 2026

1. Scope

Hermes Workspace is a private, single-user automation application. It has exactly one user: the owner of the Google Account that authorized it (novastreamde@gmail.com). The application is not offered to, distributed to, or accessible by any other person.

2. What data is accessed

With the owner's explicit consent, the application accesses the following data on the owner's own Google Account only:

  • Google Calendar — event titles, times, locations, attendees
  • Google Drive — file names, metadata and file contents of files the owner opens
  • Google Sheets — cell values and spreadsheet contents
  • Google Docs — document titles and body text

3. How the data is used

The data is used only to perform tasks the owner explicitly requests, such as reading a spreadsheet range, appending rows, listing calendar events, or creating a document. All processing happens on the owner's own private server.

4. What is stored

OAuth access and refresh tokens are stored on the owner's private server so the connection stays active between sessions. No other Google user data is retained beyond the duration of the requested task.

5. Sharing and disclosure

No Google user data is sold, rented, published, or shared with any third party. No data is used for advertising. No analytics or tracking is performed. Data is transmitted only to Google's own APIs, over encrypted connections.

6. Retention and deletion

The owner may revoke access at any time, which immediately and permanently ends the application's ability to read or write any data. Revoke access at myaccount.google.com/permissions by removing "Hermes Workspace".

7. Security

The application runs on a private server with no public inbound access. Credentials are stored with owner-only file permissions and are never transmitted to third parties.

8. Contact

Questions about this policy: novastreamde@gmail.com
